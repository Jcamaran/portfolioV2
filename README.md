# Joaquin's Portfolio

Welcome to the little corner of the internet where I collect the things I build, explore, and occasionally make spin in 3D.

This is my personal portfolio: part resume, part playground, and part experiment in turning ideas into interactive experiences.

## Built with

- Next.js and React
- TypeScript
- Three.js / React Three Fiber
- Framer Motion
- Tailwind CSS

## Run it locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) and take a look around.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the local development server |
| `npm run build` | Creates a production build |
| `npm run start` | Serves the production build |
| `npm run lint` | Checks the code with ESLint |
